# Service demonstration assets

`iphone-air-clay.webp`: native IPHONE AIR BODY raster layer exported from the user-provided Vertex Lab iPhone Air Clay Mockup Kit Lite, frontal top-down PSD. Original body bounds 2368,942–3632,3558 in a 6000×4500 source; resized to 760×1573, WebP quality 90. The live DOM screen aligns to the source DISPLAY MASK. Source ZIP/PSD remains outside the repository. No generated replacement for the supplied device.

`chat-pattern.svg`: original decorative line pattern authored for this demonstration. The WhatsApp-inspired interface is live HTML/CSS with fictional local conversation content. Personal conversations and photos in the user's reference screenshots are not included.

The refined wallpaper uses 26 reusable outlined motifs in 27 placements: everyday objects, nature, music, food and small geometric accents. Rounded fine strokes, varied rotations and a phone-relative tile size follow the supplied screenshot references. External visual research: [WhatsApp — Chat themes to reflect your style](https://blog.whatsapp.com/chat-themes-to-reflect-your-style). No wallpaper asset was downloaded or copied from that source.
